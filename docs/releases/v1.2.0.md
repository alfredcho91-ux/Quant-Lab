# Quant-Lab v1.2.0 — 손절 실험실

## 업데이트

- 기존 변동성·꼬리 통계 페이지를 Stop-Loss Lab으로 확장했습니다.
  `/volatility-statistics` 경로를 유지하며 `/stop-loss-lab`에서도 열 수 있습니다.
- 일봉·주봉의 꼬리, TR, Wilder ATR, MTR에 대해 평균·중위값·모집단 표준편차와
  P50/P75/P90/P95/P99를 제공합니다. 새 분포의 %는 각 봉의 시가 기준이며,
  길이 0인 꼬리도 포함합니다. 히스토그램은 0.1%p 구간입니다.
- 이전 확정 고점/저점·시가·종가·꼬리 극값·확정 스윙을 기준으로 진입/손절/익절
  조건을 실험합니다. 고정 %, ATR/MTR·꼬리 배수, 과거 백분위수,
  이전 완료 진입 조건의 MAE 상한 기반 손절을 지원합니다.
- 하위 시간봉으로 시장가 접촉 체결을 시뮬레이션하고 수수료·슬리피지·갭,
  보유기간 종료, 재진입 제한, 위험 기반 수량과 1배 명목 상한을 반영합니다.
- 클릭형 손절/익절 히트맵, 승률·실현 손익비·기대값 R·PF·순수익률·낙폭,
  MAE/MFE 상·하한, 거래 내역을 제공합니다.
- 시간순 학습/표본 외 검증과 경계 횡단 거래 제외, 인접 파라미터 안정성,
  연도·추세·변동성 구간 비교 및 확장 학습 순차 검증을 제공합니다.
- 기존 봉별 수치 테이블은 별도 탭에 보존했습니다. TR 산술평균/중위값,
  윗꼬리·아랫꼬리 평균/중위값과 종가 기준 %를 명시적으로 구분합니다.
- 한국어 봉 기간 표기(4시간봉·날봉·주봉·달봉), 소수점 두 자리 표시,
  직접 URL 접근과 새로고침을 지원합니다.

## 검증 및 한계

- 구현 승인 시 로컬 백엔드 1,276개 통과 / 1개 건너뜀,
  프런트엔드 580개 통과. TypeScript·ESLint·프로덕션 빌드·구조 및 공백 검사 통과.
- 합성 OHLC로 체결·비용·미래 데이터 차단·학습/검증 분리를 테스트했습니다.
  실제 공개 Binance BTC USDT-M 시세의 데이터 조회·계산·브라우저 동작도 확인했습니다.
- 동일 봉에서 손절·익절이 모두 발생하면 보수적으로 손절 우선 처리하고 표시합니다.
  진입 전후 순서가 불명확한 거래는 평가에서 제외하고 건수를 공개합니다.
- 꼬리 백분위수는 진입 후 손절 확률이 아닙니다. MAE/MFE는 OHLC 상·하한이며,
  틱 단위 체결, 펀딩·레버리지 청산·유동성·실제 주문 정밀도는 모델링하지 않습니다.
- 낙폭은 청산 계좌 기준입니다. 신뢰구간은 연속 의존성·다중 실험을 보정하지 않습니다.
  관측 분포와 반사실 시뮬레이션을 구분하며 수익을 보장하거나 자동 주문하지 않습니다.
- 자세한 계산·체결 가정과 검증 범위: [Stop-Loss Lab](../STOP_LOSS_LAB.md).

## 배포 범위

기존 릴리스와 동일한 **소스 배포**입니다. GitHub의 Source code ZIP/TAR를 제공하며,
Windows 설치 파일·실행 파일은 포함하지 않습니다. 기존 로컬 앱을 사용 중이라면
소스를 업데이트하고 백엔드와 프런트엔드를 재시작해야 새 기능이 반영됩니다.
새 의존성이나 데이터베이스 마이그레이션을 추가하지 않았습니다.
