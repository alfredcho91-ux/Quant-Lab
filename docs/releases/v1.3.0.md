# Quant Lab v1.3.0 — Windows 독립 앱

## 다운로드 및 실행

아래 첨부 파일 **Quant-Lab-Windows.zip**을 내려받아 전체 압축을 해제하고
`Quant Lab/Quant Lab.exe`를 실행하세요. `_internal` 폴더를 함께 유지해야 합니다.
Chrome 탭이나 별도 Python·Node.js 개발 서버 없이 독립 앱 창으로 실행됩니다.
Microsoft Edge WebView2 Runtime이 필요하며 현재 ZIP은 **코드 서명되지 않은 포터블 앱**입니다.
Microsoft Store 설치 패키지는 아닙니다.

## 업데이트

- 독립 Windows 창, 중복 실행 시 기존 창 활성화, 창 종료 시 로컬 서버 종료.
- 기존 미저장 편집·저장 중 작업의 이동 보호 정책 유지.
- 봉 통계는 날짜 대신 최근 완료 일봉 수로 조회: 기본 90개, 1–10,000개.
- 진행 봉·지표 준비 봉을 표본에서 제외하고 실제 확보 봉 수를 표시.
- 전체/주말 일봉 표본과 기존 상세 봉별 통계 유지.
- `P50` → 중위값, `P90` → 90% 기준값 등 읽기 쉬운 표기.
- `TR` → 봉 변동폭, `ATR` → 평균 변동폭, `MTR` → 변동폭 중위값.
  계산 방식과 전략 API 식별자는 유지합니다.
- 패키지 기본 캐시를 사용자 데이터 폴더로 분리하여 설치 폴더에 쓰지 않음.

## 데이터 및 주의사항

실제 거래 DB·API 키·`.env`·CSV 기록은 배포 파일에 포함되지 않습니다.
데이터·설정은 `%APPDATA%\Quant Lab`에 저장되며 기존 소스 폴더의 기록을 자동으로
옮기거나 삭제하지 않습니다. 소스 실행과 패키지 실행의 데이터 위치 차이에 유의하세요.
시세 조회에는 인터넷이 필요합니다. 통계·백테스트는 과거 관측과 가정에 따른 연구이며
자동매매나 수익 보장이 아닙니다.
